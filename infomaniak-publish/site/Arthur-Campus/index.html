01Campus field

Un campus, pas une trajectoire.

Les bâtiments sont des champs de travail. Les Master Classes sont des portes. On peut entrer par Python, le jeu, l’IA locale, le Web ou une question de recherche — puis traverser vers ailleurs quand le projet l’exige.

Clique sur une zone de la carte. Les connexions représentent des passages possibles, pas un ordre de progression.

02Master Classes

Seize portes actuellement ouvertes.

Chaque Master Class contient une question, un champ conceptuel, des laboratoires et quelque chose à construire. Aucun “niveau” n’est une identité : les prérequis sont appelés localement lorsqu’ils deviennent nécessaires.

03External field

Visiting Institutions & Open Learning.

Le Campus ne fabrique pas de faux diplôme. Il se branche sur des institutions réelles lorsque leur présence, leurs crédits, leurs enseignants, leurs communautés ou leur profondeur apportent quelque chose que le laboratoire personnel n’a pas.

42Lausanne / Renens

La piste présentielle la plus singulière.

42 Lausanne est gratuite, accessible dès 18 ans sans diplôme ni expérience préalable, organisée par projets et peer-to-peer. Son cursus actuel mentionne explicitement algorithmique, administration système, Python orienté objet, LLM, RAG et agents IA. La Piscine dure quatre semaines ; le cursus complet est annoncé sur 3 à 5 ans indicatifs.

04Orion Lab

Le PC devient un laboratoire d’IA locale.

Le Predator Orion 7000 de 2024 ouvre une deuxième voie : ne pas seulement appeler des modèles dans le cloud, mais comprendre ce que signifie réellement charger, quantifier, servir et mesurer un modèle sur sa propre machine.

Phase zero
Hardware audit — avant toute hypothèseRelever CPU, RAM, GPU exact, VRAM, stockage, pilotes et résultats de nvidia-smi. Le modèle choisi dépend de cette configuration réelle.
Local UI
LM StudioWindows x64 pris en charge ; 16 GB RAM recommandés et au moins 4 GB de VRAM dédiée conseillé. Modèles locaux et serveur API local.
Local API
OllamaAccélération GPU NVIDIA sous Windows, bibliothèque de modèles et API locale. Les versions 2026 ont encore amélioré les performances sur NVIDIA.
Deeper
Transformers + PyTorchLorsque l’interface ne suffit plus : chargement direct, tensors, modèles, quantification, expérimentation et code Python.
Le but du Local Lab n’est pas de “remplacer le cloud”. Il sert à faire apparaître les différences de régime : confidentialité, latence, coût marginal, mémoire, taille des modèles, dépendance réseau, contrôle et limites matérielles.
05Infrastructure

Local ↔ Git ↔ Infomaniak ↔ Web.

L’infrastructure elle-même devient matière d’apprentissage. Le projet peut commencer en HTML pur, puis accueillir Python/PHP, bases MariaDB, Git, SSH et — lorsque le besoin apparaît — Node.js.

Local

06Proof / traces

La progression n’est pas un pourcentage. Elle apparaît par des traces qui peuvent être relues, reprises ou abandonnées sans effacer ce qui a été compris.

07Principles

Une pédagogie de terrain.

Le Campus s’inspire moins du cours magistral que du studio, du laboratoire, de l’open courseware et du project-based learning — avec une IA présente, mais jamais prise pour la preuve de ce qu’elle affirme.

A

Build first, explain deeply

Construire assez tôt pour rencontrer des problèmes réels, puis revenir vers les concepts qui rendent ces problèmes lisibles.

B

Sources stay attached

Documentation primaire, provenance et version des outils accompagnent les résultats. Une réponse IA seule n’est pas une source.

C

Multiple entrances

Code, jeu, art, agents, Web ou data peuvent être des entrées légitimes. Les passages se font par besoin, pas par classement.

D

Tools may be replaced

Aucun framework ni fournisseur ne définit le Campus. Les outils restent interchangeables si le projet découvre une meilleure manière de tenir.

Nom public. En Suisse, « université / university » est une dénomination protégée soumise à accréditation institutionnelle. Le nom public retenu ici est donc Arthur’s Campus, avec la mention explicite Independent Learning Campus.
